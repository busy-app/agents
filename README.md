# BUSY Bar: start here for AI agents

[start.md](start.md) is the entry point for AI coding agents helping someone make something for BUSY Bar: an app, a
widget, a catalog submission or a firmware change. It checks what it can, asks the rest, and sends the agent to the
one document that fits. [go.busy.app/agents](https://go.busy.app/agents) points to it.

Give an agent this prompt:

```text
Read https://go.busy.app/agents and follow it. <what you want to make>
```

Docs for people: [docs.busy.app](https://docs.busy.app/bar/dev/js-apps).
